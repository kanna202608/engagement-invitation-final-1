Engagement invitation project

Files:
- index.html
- styles.css
- script.js
- assets/hands-joined.webp            (joined hands shown while the invitation opens)
- assets/ganesha.png                  (Ganesha artwork on the opening screen)
- assets/scene/                       (hero artwork and couple portraits)
-   groom1.jpg                        (groom portrait in the family carousel)
-   bride.avif                        (bride portrait in the family carousel)
- music.mp3                           (optional background music)

Run locally:
  Option 1: open this folder in VS Code and use Live Server on index.html
  Option 2: in this folder run   python3 -m http.server 8000
            then open http://localhost:8000
(Opening index.html by double-click also works, but a local server is recommended.)

What happens on "Open Invitation":
1. The two hands glide in, then the joined-hands image appears.
2. The hero opens: banana leaves slide in from the sides, the bells ring and then
   keep swinging gently, lamp flames flicker, and the text settles in.
3. Swipe or use the arrow keys on either family card to find the scratch card,
   then scratch it to reveal the portrait.
